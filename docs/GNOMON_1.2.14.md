# Gnomon 1.2.14 的常用入口

默认底栏为“成绩查询 / 课表 / 个人中心”。更新时，旧默认两栏或四栏会切到这个组合；自行改过的其他组合继续保留。在个人中心 → 应用偏好设置可增减入口，也可恢复默认三栏。隐藏底栏入口不会删除课表或成绩。

个人中心直接列出以下入口，均在应用内打开：

- 应用偏好设置：主题、玻璃材质、时间栏、触感、返回与底栏。
- 更新设置：当前版本、检查更新、提醒和 Beta。发现新版后可在应用内下载 APK，再由系统确认安装。应用不会静默安装。
- 关于应用：介绍、版本日志、源码、致谢和支持；项目网页在应用内浏览。
- 课表导入：选 JSON 或 ICS，先查看预览，确认后新增课表；不覆盖原表。
- 课表导出：选择课表与 JSON / ICS 格式，再选择保存位置。
- 课表备份与恢复：完整备份、本机历史与手动 WebDAV。

默认液态沿用原组件的形状、采样与选中标签。高斯和柔光调整背景采样，不再把所有控件强制变成同一圆角。课程圆角仍在布局设置里调整。若此前保存过材质参数，可在“玻璃材质”选择液态，点“恢复原版液态玻璃”，再点“应用”。取消预览不会写入。

本轮不改变学校认证、课程数据库或提醒规则。未连接手机，未安装或启动应用；主机检查不能替代三种材质与整套操作的实机验收。
