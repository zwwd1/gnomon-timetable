# Gnomon 课程表使用说明

想把课程、作息和提醒安排好，选 Gnomon；想把课表、成绩和更多教务入口放在一起，可以选 [Lumen](https://github.com/zwwd1/lumen-timetable)。按自己的需要选一款就行，两款的数据各自保存。

下面是 2026 年 10 月 12 日的真实手机截图，拍摄早于这次英文改名与新版使用指南。图中没有账号、密码或个人成绩；界面文字可能与后续版本略有差别。

## 1. 安装后先连接学校

已经安装过的，直接覆盖安装，原来的课表和设置继续保留。第一次打开且没有账号与课程时，会出现连接邀请；选择“连接川职教务”，在应用登录页输入学号和学校统一认证密码，再点“登录并自动同步”。

凭据加密保存在这次安装的手机中。以后优先复用学校会话，过期时尝试自动恢复。换手机、清除应用数据或学校改密码后，需要重新连接；学校强制的验证码和二次认证也需要本人完成。

选择“稍后”也可以手动添加课程。以后从设置中的“自动刷新课表”，或课程菜单中的“教务系统导入”连接学校。

<img src="images/timetable-empty.png" width="300" alt="Gnomon 真机周课表：尚未同步，右上角有编辑、菜单和刷新入口">

这是尚未连接时的周课表。右上角铅笔进入编辑，三点菜单提供导入与课表操作，刷新按钮读取已连接的账号。图里的节次时间来自当时手机的本地设置，**不是学校官方作息表**。

## 2. 学校要求补充认证时

应用登录页提供“打开学校认证页”。只有需要学校验证码、二次认证或处理账号安全提示时，才在这里按学校要求操作。网页右上角三点菜单可以刷新、回到教务首页或重新认证。

<img src="images/school-auth.png" width="300" alt="Gnomon 真机学校统一身份认证页，学号和密码均为空">

认证完成后，应用核验当前学生身份，再读取和保存课表。遇到同步未完成，可以保留当前认证重试；已有课表不会因这次请求失败被清空。

## 3. 查看课程，设置准确提醒

在课程页切换日、周视图和教学周，点按课程会放大卡片，醒目显示课名、老师、地点与时间。长按课程打开快捷操作，选择“编辑单节课”；也可以长按放大的卡片进入编辑。手动添加和修改会在后续同步中保留。

打开当前课表设置，核对开学日期和节次时间，再开启提醒。学校接口没有提供钟点时，不会编造上下课时间；请按实际作息填写，并允许应用发送通知。

“自动刷新课表”里可选每天、每七天或关闭，也可立即刷新。自动任务实际何时执行由 Android 和手机的后台限制决定；需要立刻核对时使用手动刷新。

## 4. 成绩、外观与底栏

设置中的“成绩与学分”先显示本机记录。取得学校成绩后，切换学期、搜索和筛选都使用已保存的数据；毕业学分要求随后读取。学校没有返回的要求不会当成零，也不能据此判断是否能毕业。

通用设置可以调整液态玻璃、壁纸、入场动画与底栏入口。底栏可以增减成绩和教务同步等入口，设置入口始终保留。桌面小组件、课程导出和备份沿用各自的原生入口。

AI 助手需要配置自己的模型服务。“附带课程信息”默认关闭，学校密码不会用于 AI 请求。

## 遇到问题

| 现象 | 可以怎么做 |
| --- | --- |
| 课表为空或教学周不对 | 核对账号、所选学期和首周日期，再手动刷新；正常空周也可能没有课程 |
| 学校请求很慢或失败 | 保留现有课表，稍后重试；确需补充认证时打开官方页面 |
| 改了学校密码 | 在应用登录页重新输入新密码，建立新的本机恢复凭据 |
| 后台没有及时更新 | 检查应用的联网和后台权限；不能把系统延后执行当成已经同步 |
| 换手机或需要备份 | 先导出课程与设置，再在新手机登录；普通备份不携带学校密码 |
| 想退出账号 | 退出登录会移除本机认证并取消自动同步，离线课表继续保留 |

云服务目前暂停。导出的文件由你自己选择存放位置，别把个人课表、账号或登录截图贴到公开问题里。

我不会实时维护，学校改登录方式或接口后可能失效。源码和构建方法都在，有需要可以 fork，自行 vibe coding。
