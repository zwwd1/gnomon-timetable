# 1.2.13 使用补充

原来的[实机图文说明](SCVTC_USAGE.md)仍可参考。现有图片来自此前版本；本轮没有连接手机，也没有拿效果图冒充新包截图。

## 作息与节次

打开「设置 → 课表详细设置 → 课表节次与时间」。节次数量在一处调整，上午、中午、下午、晚上分别保留；各作息整行可点开编辑。「生效中」标出当前采用的方案，查看另一套不会顺便启用它。

进入作息后可以改名、逐节填写起止时间，或进入原有时间轴调整课长和课间。缺失时间仍有占位行，不再因为解析失败整行消失。主课表点左侧时间栏，也能直达相应节次。未知节次可先留空，开始与结束必须同时填写；不会为这些节次安排提醒或导出日历事件。

新增方案沿用向导；从其他课表复制只读取来源当前作息，节次数量须一致，不修改来源。子页面完成后先回到草稿，最后在课表详细设置点「完成」统一保存。涉及课程节次映射时会先确认；有独立逐节铃声、无法安全映射的课程会阻止保存并提示处理。

没有方案时可用「建立作息」恢复编辑入口，优先保留已知时间。失效的当前方案关联会提示重新选用，原有方案不自动清除。

## 时间栏与休息分隔

时间栏默认显示编号、开始、结束；行高不足时允许纵向滚动。只有主动关闭「显示节次时间」才只留编号。

午休、晚休是 24dp 的显示分隔，不是新增课程或节次。位置来自本课表的真实分段与当前作息，不固定在第 4、8 节之后。中午有教学时，仅从其前后可确认的空档选择午休；未知时保留教学，不猜测整段中午都是休息。无晚课、零间隔或有自定义时间课程占用空档时不画对应分隔。时间完整时显示实际起止，否则只在能确定的边界显示名称。

时间栏、卡片、复制命中、拖动、缩放与详情回落共用布局映射。跨越休息带的同一课程分段显示，编辑时仍是一门课程。休息分隔不进入提醒、桌面组件数据和 ICS 课程事件。

## 应用偏好与预览

「设置 → 应用偏好设置」中可切换主题预览、跟随系统、首页模式、时间栏、休息分隔、周课表教师地点显隐、返回手势、触感和更新选项。

- 主题、首页模式、壁纸、课程卡尺寸和字体跟随当前课表。
- 材质参数、着色、详情透明度、时间栏与休息开关、周课表教师地点开关适用于全部课表。
- 材质质量与样式分开。最佳保留配置的折射与色散；均衡、性能降低模糊与折射并关闭色散，不重写三套参数，也不压低文字对比度。

「玻璃材质」里分为壁纸、效果、布局，预览使用本机课程与作息。液态、高斯、柔光分别记住参数。取消恢复进入时的预览，应用后保存；退出不自动提交未应用的更改。换图先采用居中裁剪，精细裁剪沿用原有主页外观入口。

## 文件与备份

「设置 → 数据管理」：

- **JSON 课表**：导入先查看课程与作息摘要，再新增一张课表。保留多套作息、调休和课程自定义时间，不含壁纸文件、登录信息、AI 会话。可导出所选课表，已有同名课表也不会被覆盖。
- **ICS 日历**：支持定时事件、日 / 周重复、排除和附加日期。按北京时间保存，带时区的重复事件先按来源时区展开，以保留夏令时变化。导出使用实际日历日期和调休映射；缺时间会明确跳过。跨零点、未支持的重复规则及重复例外会跳过或提示先拆分，日历不是完整备份格式。
- **本机备份历史**：保存完整备份、预览内容、恢复或删除指定记录。删除会确认；恢复沿用原有校验、映射与回滚流程。
- **WebDAV**：填最终 HTTPS 目录地址、账号与应用密码。连接信息在手机加密保存，不随普通备份导出。手动上传先生成本机完整备份，再上传为唯一历史文件；不覆盖旧文件，不增加常驻同步服务。可浏览远端历史，下载并校验后再确认恢复。需要服务器支持 MKCOL、PUT、PROPFIND 和 GET。

「设置 → 应用偏好设置 → 更新设置」集中显示当前版本、手动检查、每日检查、更新提醒和 Beta 选项。实际发布源仍为本项目 GitHub，没有添加不可用的数据源选择器。

## 本轮检查范围

进行当前改动所需的定向规则与文件协议检查，正式安装包沿用 Release、R8、lintVital 与原签名。准确结果及源码对应关系见根目录 VERIFICATION.md、BUILD_PROVENANCE.json。

未连接手机，实际点击、旋转、返回取消、复杂壁纸布局和 FPS 均未实机验收；外部 WebDAV 服务、真实学校会话到期也未在本轮联调。可选的下课烟花没有加入，优先完成作息、数据和课表流程。

布局职责参考了 [NexioSchedule](https://github.com/HaoZai000/NexioSchedule) 的节次与特殊分隔共用几何思路，本轮在 Gnomon 内独立实现，没有引入其整套 KMP 工程或新增界面依赖。
