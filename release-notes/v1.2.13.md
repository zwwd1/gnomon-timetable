# Gnomon 课程表 1.2.13

这次先把作息设置的路理顺，再补课表上的时间和休息分隔。新增的数据操作也都接到了文件和备份流程里。

• 理顺课表详细设置：节次数量、作息列表、逐节编辑、时间轴、添加与复制各有入口，查看和启用作息分开。
• 缺时间的节次照常列出，可以逐节填写；调整节数时保留已知时间，不替用户编一套学校作息。
• 周课表默认显示节次起止时间，增加按实际分段计算的午休、晚休分隔，保留午间教学；移动、复制和详情回落同步使用新的位置。
• 课程卡突出课名、地点和教师，详情随内容收拢；可分别选择液态、高斯、柔光及材质质量。壁纸、效果与布局预览可取消或应用。
• 数据管理增加 JSON / ICS 导入预览、所选课表导出、本机备份历史及手动 WebDAV 上传、浏览和恢复。日历按北京时间与实际调休日期处理，缺少时间的安排会说明跳过数量。
• 应用偏好补上时间栏、休息分隔、教师地点显隐、预测性返回、触感和质量选项，并说明作用范围。更新设置集中显示版本、检查与提醒选项。

沿用原包名与原签名，支持覆盖安装。本轮只更新 Gnomon，Lumen 保持原版本。

手机未连接，尚未实测这份新包的触摸、旋转、键盘、返回手势与流畅度。WebDAV 已做本地协议检查，尚未对用户实际服务器联调；学校登录和自然到期恢复也没有在本轮重新实机验收。
