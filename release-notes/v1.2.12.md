# Gnomon 课程表 1.2.12

• 成绩、教务接入同一主页面，切换时保留底栏、课表位置和成绩筛选，不再反复打开独立窗口。
• 底栏增减入口时平滑调整宽度，修正拖动范围与回调；恢复默认按钮与设置内容对齐。
• 新增液态、高斯、柔光三种玻璃。各自调节、实时预览，应用后独立保存，取消不覆盖原设置。
• 缺失的节次时间可以逐节补填；调休页面不再等待活动课表的作息加载，回传时核对目标课表与草稿。
• 整理 AI 服务地址、模型和 Key 的输入布局，Key 默认遮掩，保留原有本机加密保存。

本轮仅修改 Gnomon，不改 Lumen。原课表、壁纸、作息、提醒与学校认证链路保留，沿用包名和原签名。

Release 构建、原签名与 21 项定向规则检查通过。手机操作、三种材质的实机效果和 Android 17 手势仍待复测。
